# Face Detection Attendance System

A real-time attendance system using OpenCV's Haar Cascade for face detection and LBPH for face recognition.

## Features
- Register new faces via webcam
- Real-time face recognition
- Automatic attendance logging to CSV with timestamps

## Tech Stack
Python, OpenCV, NumPy, Pandas

## How to run
1. `pip install opencv-python opencv-contrib-python numpy pandas`
2. `python register_face.py` — register a new face
3. `python main.py` — start recognition and attendance logging
